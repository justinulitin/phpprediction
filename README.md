# Philippine Peso Depreciation Early-Warning Model: Predicting the Next-Month PHP/USD Exchange Rate Using Linear Regression and PCA
This project aims to develop a regression model that predicts the next month's average Philippine peso per US dollar (PHP/USD) exchange rate using historical monthly exchange-rate data published by the Bangko Sentral ng Pilipinas (BSP). The project will demonstrate how matrices, vector spaces, linear transformations, determinants, eigenvalues, eigenvectors, diagonalization, and principal component analysis (PCA) can be applied to prepare and analyze data and evaluate a regression model.

The value of the Philippine peso against the US dollar changes over time. When the exchange rate increases in PHP per US dollar, more pesos are needed to buy one US dollar. This indicates that the peso has weakened against the dollar. These changes may affect businesses that import goods, families paying dollar-denominated expenses, travelers, and people who regularly convert money between pesos and dollars.

This project aims to predict the next month's average PHP/USD exchange rate using only historical information available before the target month. The predicted rate may then be used as an early-warning indicator of possible peso depreciation or appreciation. However, the prediction is not a guarantee of future exchange-rate movements and does not explain the economic causes of those movements.

Specifically, the project seeks to answer the following questions:
How can historical monthly exchange rates be organized and analyzed using matrices?
How can Linear Algebra concepts be applied to standardize and transform exchange-rate features?
How accurately can a regression model predict the next month's average PHP/USD exchange rate using historical information?
How does reducing the number of features through PCA affect regression performance compared with using all selected features            ?

Regression is appropriate because the target variable is a continuous numerical value: the next month's average number of Philippine pesos required to buy one US dollar.
